Primary stack:

LangGraph

LangGraph was selected because DrugDev-AI requires stateful, multi-step AI workflows involving retrieval, reranking, lesson generation, quiz generation, evaluation and progression. It provides more control over application logic and state than a visual automation workflow.

n8n was not selected as the primary MVP stack because the core application requires custom Python logic and AI orchestration rather than primarily event-driven automation.

n8n remains relevant for future features such as scheduled Monitor searches and Slack, Telegram or Teams notifications.
